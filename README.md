# 洪涝新闻候选语料（8302条）

本仓库保存“洪涝新闻分层语义过滤”实验使用的冻结新闻语料，共8302个新闻目录。数据以新闻标题作为目录名，以目录名作为项目中的`news_id`。

## 数据结构

```text
content/
├── 新闻标题A/
│   ├── content.md
│   └── img.json
├── 新闻标题B/
│   ├── content.md
│   ├── content(1).md
│   └── img(1).json
└── ...
```

- 新闻目录：8302个；
- 主正文`content.md`：8302个；
- 补充Markdown文件：416个；
- JSON元数据文件：5817个；
- JFIF图片：6个；
- 文本编码：UTF-8。

每个主正文通常包含标题、来源、发布时间和新闻正文。部分目录还保留了采集时产生的补充文本、图片元数据或图片文件。

## 完整性文件

- `dataset_inventory.csv`：逐文件记录`news_id`、相对路径、文件大小和SHA-256；
- `dataset_summary.json`：记录新闻数、文件类型分布、总体积和清单生成时间；
- `scripts/build_inventory.py`：重新生成完整性清单。

## 使用边界

1. 本仓库仅保存冻结实验语料，不包含BGE-M3向量、模型权重、人工标注或论文实验输出。
2. 新闻正文及图片的著作权归原作者和原发布机构所有。本仓库未对第三方新闻内容授予开源再分发许可。
3. 在确认数据来源许可、转载条件和个人信息处理要求前，仓库应保持私有。
4. 如用于研究复现，应保留原始来源信息，不应将本语料重新包装为自有新闻内容。

## 当前口径

该数据集对应论文当前唯一正式数据规模：`N = 8302`。
